# 02 — 多語系字串

**What to build:** `agens-view/hooks/i18n.ts`：
- zh-TW「需要你處理」全部改成「待處理」（分區名、頁首 `▲ n 個待處理`、`✓ 沒有待處理的 Session`、種類、按鈕）；zh-CN 同步改成「待处理」。en、ja、ko 不變。

- 語言選項用母語名稱（en 寫 English）。
- ja「待機中」、ko「유휴」：不改成任何意思是「等待」的詞；在 Comments 記下待母語者確認。
