CLI 監看視窗原型（用完即丟）

監看視窗在終端機裡應該長怎樣？用底部切換列或 ← → 鍵切換 3 種樣式，上方切換終端機大小和模式。資料是假的。

  • A 照搬 Desktop：把現在 Pane 的樹原樣畫進終端機（外框卡片、分區、[ 前往處理 → ] 按鈕）。
  • B 精簡表格：一個 Session 一行，像 htop／k9s；需要你處理的多一行摘要，用方向鍵選、Enter 前往。
  • C 待處理優先：只把需要你處理的完整列出，工作中、閒置各折成一行，Pane 盡量矮。
  • 假設：停靠時 Pane 寬約為終端機的 38%（40–64 欄），實際由引擎決定；Pane 的標題列和關閉記號是近似畫法；中日韓文字算 2 欄寬。
  • 一般模式（非全螢幕）或寬度不足 110 欄時，引擎把 Pane 嵌在輸入框上方，會擠掉對話紀錄的可見行數，看下方的統計。
