# プライバシーとデータ

[← README に戻る](../../README.ja.md)

switchboard はすべてお使いのコンピュータ上で動作し、独自のサービスにデータを送信することはありません。

- **ローカルに書き込むもの**：各セッションのステータスレポート（`<Claude 設定ディレクトリ>/switchboard/reports/<sessionId>.json`、平文の JSON）。内容は最初のプロンプトの先頭約 40 文字（タイトル用）、モデル、ブランチ、ToDo の進捗、現在の操作、承認リクエストの概要、質問、エラー、最後の返信の短い抜粋、バックグラウンドタスク、レート制限、コネクタ、プルリクエスト、実行しているターミナル（`TERM_PROGRAM`）、コンテキストの使用量、コスト、ターン数、タイムスタンプ。`sessionId` がどのセッション記録にもなく、1 分以上更新されていないレポートは、次にいずれかのセッションがスキャンしたときに削除されます。監視ウィンドウを一度も開かなくても削除されます。セッションの記録が 1 件も見つからないときは削除しません
- **マスクはベストエフォート**：書き込む前に、コマンド・承認リクエストの概要・質問・最初のプロンプト・最後の返信の抜粋・エラーメッセージに含まれる機密らしき部分（`Bearer …`、`token=…`、`--token …`、`API_KEY=…`、`sk-…`、`ghp_…` など）を `•••` に置き換えます。すべてを検出できるわけではなく、コマンドのそれ以外の部分は平文のまま保存されます
- **ローカルで読むもの**：Claude Code 自身の `<Claude 設定ディレクトリ>/sessions/*.json` とこれらのレポート。他のセッションの `.jsonl` 会話ログは読みません
- **ネットワークへの接続**：switchboard 自身が接続するのは 2 つの場合だけです。1 つは `gh pr view`（次の項目を参照）。もう 1 つは更新の確認で、すべてのセッションを合わせて 1 時間に 1 回まで、セッションの開始から約 1 分後に初めて判断し、期限が来ているときだけ接続します。`https://raw.githubusercontent.com/wide3751/switchboard/main/agens-view/.claude-plugin/plugin.json` から公開されているバージョン番号を読み、10 秒応答がなければあきらめます。公開ファイルをダウンロードするだけで、ローカルのデータは一切送りません。最後に確認した時刻、見つけたバージョン、スキップしたバージョン、インストールしたばかりのバージョンは、Claude Code がプラグインに用意する共有ストレージに保存します。止めるには、**設定 ▸ › 一般** で「更新を確認」をオフにするか、`DISABLE_UPDATES`、`CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC` のどれかの環境変数を設定します
- **実行するコマンド**：スキャン時に `ps`（Windows では `tasklist`。どのセッションが生きているか。監視ウィンドウを閉じている間も、開くボタンの件数のために 15 秒ごとに実行）と `rm`（残ったレポートの削除）。各セッションの開始時と各ターンの終了後に、そのセッションのフォルダで `git`（ブランチと変更）と `gh pr view`（プルリクエスト。あなた自身の `gh` ログインで GitHub に接続）。ほかに `uname -s`（`/switchboard:open` のときに OS を判定）、`defaults read -g AppleLanguages`（UI の言語。`LC_ALL`、`LANG` で言語が決まらないときだけ実行）、`open`（Desktop セッションへの移動と、プルリクエストのページや作者リンクを開く）、`osascript`（iTerm・Terminal.app の該当タブへの切り替え）、`claude plugin marketplace update switchboard` と `claude plugin update switchboard@switchboard`（新しいバージョンのお知らせで「今すぐ更新」を押したときだけ順に実行。Claude Code が新しいバージョンをダウンロードしてインストールします）。Windows では `rm` の代わりに `cmd /c del`、`open` の代わりに `rundll32 url.dll,FileProtocolHandler` を使います。タイムアウト：`ps`・`tasklist`・`git` は 5 秒、`gh` は 8 秒、`osascript` は 10 秒、`defaults` と `uname` は 3 秒、2 つの `claude plugin` コマンドは合わせて 60 秒

## 仕組み

すべてのセッションに mod が読み込まれ、次の 2 つの役割を持ちます：

1. **Reporter**：自分のセッションのイベント（`session.start`、`turn.start`、`tool.call`、`turn.complete` など）を受け取り、ステータスレポートを書き出します。セッションの開始時と各ターンの終了後には、ブランチ・変更・プルリクエストのために自分のフォルダで `git`、`gh` も実行します。
2. **監視ウィンドウ**：監視ウィンドウを表示しているセッションは、3 秒ごとにレポートと Claude Code のセッション記録を統合し、プロセスが存在しないセッションを除外して一覧を描画します。自分では `git`、`gh` を実行しません。監視ウィンドウを開いていないセッションは、同じ統合を 15 秒ごとに行い、入力欄の上のボタン用に対応待ちの件数だけを数えます。

セッションが存在するかどうかは、Claude Code 自身の記録とプロセスが生きているかだけで判断するので、古いレポートが残っていても終了したセッションが一覧に残ることはありません。2 つの情報源が食い違う場合は、決まった順序で判断します。記録が作業中か対応が必要なら記録を採用し、そうでなければ、レポートにターンのエラーがあればエラー停止、レポートに質問があり記録が待機中なら対応が必要とします。それ以外は記録を採用します。
